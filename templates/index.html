Field notes

Policy quick reference

FCFS
First come, first served

Non-preemptive. Arrival order decides the next dispatch.

→
SJF
Shortest job first

Non-preemptive. The smallest burst in the ready queue runs first.

→
PRI
Priority scheduling

Lower priority values receive the CPU first in the default convention.

→
RR
Round Robin

Preemptive rotation. Set a quantum to balance fairness and overhead.
